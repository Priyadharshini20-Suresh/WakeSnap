# WakeSnap – Smart Picture Alarm

## Project Overview

WakeSnap is a Smart Picture Alarm Web Application designed to make waking up more interactive. Users can set an alarm, select a picture and complete a picture capture challenge to stop the alarm.

## Features

- User Login and Registration
- Smart Alarm Interface
- Picture Capture Challenge
- User Dashboard
- Daily Routine Statistics

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Main webpage
- `style.css` – Website design and styling
- `script.js` – Website functionality
